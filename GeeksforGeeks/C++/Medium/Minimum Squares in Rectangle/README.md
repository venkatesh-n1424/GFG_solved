### 📜 Problem Description

Given two integers  **n**  and  **m** , representing the length and breadth of a rectangle. Find the minimum number of squares required to completely fill the rectangle such that no two squares overlap.

**Examples:**

```
Input: n = 4, m = 5
Output: 5
Explanation: One square of size 4 x 4 and four squares of size 1 x 1 are required.
```

```
Input: n = 2, m = 4
Output:  2
Explanation: Two squares of size 2 x 2 are enough to fill the rectangle.
```

**Constraints:** 
1 ≤ n, m ≤ 109
